# Useful Skills for Codex

This folder is the Codex plugin bundle of [harness-useful-skills](https://github.com/MSpiechowicz/harness-useful-skills), generated by `scripts/build-codex-plugin.js`; do not edit it by hand except this README.

- `.codex-plugin/plugin.json` is the plugin manifest.
- `skills/` holds the 21 `us-*` skills.

The marketplace is `harness-useful-skills`, the plugin is `useful-skills`, and the plugin ID is `useful-skills@harness-useful-skills`. Installing only the plugin gives you the skills, as `useful-skills:us-*`, but no agents and no memory tools:

```sh
codex plugin marketplace add MSpiechowicz/harness-useful-skills
codex plugin add useful-skills@harness-useful-skills
```

The seven `us-*` role agents and the memory tools (the MCP server `useful_skills`) are not part of the plugin: Codex does not expand `${PLUGIN_ROOT}` in a plugin's `.mcp.json` and gives plugin servers no workspace, so the Useful Skills installer registers the server instead. With Node.js 22+ and the `codex` CLI on `PATH`, run it from a checkout or release:

```sh
./useful-skills install --host codex [--local]
```

Or run the install script with `HARNESS_SKILLS_HOST=codex`. Restart Codex afterwards. Without the installer the skills still load, but `us-run-workflow` reports the missing agent types.

Workflow stages are static guidance in Codex; to skip the workflow for one request, invoke `$us-ignore-workflow` directly. To update, re-run the installer. `./useful-skills uninstall --host codex` and `./useful-skills doctor --host codex` remove and check the installation. See the [repository README](https://github.com/MSpiechowicz/harness-useful-skills#codex) for what is installed, the limits, and how memory works.
