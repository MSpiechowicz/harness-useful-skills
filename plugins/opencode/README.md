# Useful Skills for OpenCode

This folder is the OpenCode bundle of [harness-useful-skills](https://github.com/MSpiechowicz/harness-useful-skills), generated by `scripts/build-opencode-plugin.js`; do not edit it by hand except this README.

- `useful-skills.js` is the plugin entry OpenCode loads. Its default export serves both OpenCode plugin APIs (V1 `server`, V2 `setup`).
- `useful-skills/` is the runtime tree: the OpenCode adapter, the shared modules it uses, the 20 `us-*` skills, the role agent templates, the `/useful-skills` and `/us-ignore-workflow` commands, and the pinned dependency metadata and licenses.

The installer copies this bundle into an OpenCode scope; do not copy files by hand. From a checkout of the repository, with Node.js 22+ on `PATH`:

```sh
./useful-skills install --host opencode
```

Add `--scope project` to install into `.opencode/` of the current project instead of your user configuration. Restart OpenCode afterwards. See the [repository README](https://github.com/MSpiechowicz/harness-useful-skills#readme) for what the plugin runs, writes, and sends, and for update and uninstall.
